# EU CRA rerank query set (PLAN-v3.md WP5) — single source of truth.
#
# One to three English queries per CATEGORY class in
# searchinfo/searchinfo_eu_cra.md. A candidate is scored against every query
# and keeps its MAXIMUM: a CRA article belongs to one of these seven classes,
# not to all of them, so requiring a broad match would drop the specialists.
#
# English only, deliberately. bge-reranker-v2-m3 is multilingual on the
# DOCUMENT side — measured at deploy, Chinese/Japanese/Korean documents beat
# English noise on every gate query — so translating the queries would add
# variants without adding signal.
#
# Lines starting with # and blank lines are ignored. Changing this file changes
# every score, so the calibrated threshold in tracker/cra_gate.py must be
# re-derived when it changes; ops/llama-server/MANIFEST.md pins the model the
# scores depend on.
