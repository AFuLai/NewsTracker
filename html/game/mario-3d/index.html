⌨ 鍵盤操作 (常見 3D 動作配置)

  • W A S D 或方向鍵：360 度平面自由奔馳
  • Space：跳躍；起跳後於空中再次按下可短暫騰空滯空
  • Shift 或 J：高速衝刺 / (火焰瑪莉歐) 發射 3D 彈跳火球
  • C 或 Ctrl：下蹲 / (空中時) 迅速向下臀部撞擊 (Ground Pound) 破壞障礙物與踩踏金幣
  • V：切換 4 種視角（自由追蹤 / Boss戰對戰鎖定 / 45°等角立體 / 電影特寫）
  • Q / E：向左/向右旋轉視角相機
  • E / Enter：觸發機關、推進劇情對話
  • P / Esc：開啟 5 筆存檔讀檔選單

🖱 滑鼠操作

  • 滑鼠移動：環繞瑪莉歐 360 度自由旋轉視角
  • 滑鼠左鍵：確認對話 / 施放火球攻擊 / 互動
  • 滑鼠右鍵拖曳：手動環形平移鏡頭視角
  • 滾輪滾動：拉近或拉遠相機距離 (Zoom In / Out)
