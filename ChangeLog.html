v0.1 — 2026-05-29

  • 核心架構建立與 CLI 介面： 首次發布了完整的專案骨架，包含命令行介面 (CLI)、配置管理、資料提取、內容去重等核心模組，讓使用者能透過統一的介面操作所有功能。
  • 多樣化資料來源支援： 支援多種資料擷取來源，包括 API 介面、RSS Feed、本地檔案路徑 (Path) 以及更進階的 Stealth 來源，大幅提升資訊抓取能力。
  • 內容處理與 LLM 整合： 引入了資料去重 (deduplication) 邏輯，並整合了 LLM 處理模組，用於內容摘要、分析與結構化處理。
  • 打包流程建立： 完善了內容的打包與渲染機制，能夠將抓取到的多源資料轉換為標準化的輸出格式。 [✨ 標註：打包流程相關]
  • 錯誤處理與穩定性修復： 修復了自測試的退出處理邏輯，並強化了內容分類 (CATEGORY) 分隔符號的過濾條件，提升系統穩定性。
