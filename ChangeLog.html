v2.0 — 2026-06-15

  • 【核心功能升級】多層次內容過濾與驗證管線 (LLM Pipeline)：引入了全新的四層式處理流程（Gate → Summarize → Review → Probe）。新增的「審核層 (Review)」採用純 Regex 進行抗幻覺檢查，確保摘要中的 CVE ID/CVSS 分數必須出現在原始來源內，大幅提升資訊的準確性與可靠度。
  • 【來源自動偵測】新增自動化來源探測 (Auto-Probe) 功能：用戶無需手動編輯程式碼，只需提供網址，系統即可自動偵測最佳的內容抓取方式（優先順序：RSS → 網頁列表 → Ollama 分類 → Wayback Machine → 搜尋）。此功能實現了「零接觸」新增來源。
  • 【效能與覆蓋率】優化新聞抓取覆蓋率與抗噪音能力：大幅提升了對結構化噪音（如網站頁腳、隱私政策、服務條款）的排除能力。透過結合 L1 閘門和 L2 語義過濾，確保只有真正「發生在某一天」的文章內容進入處理流程，有效提升資安新聞的純淨度。
  • 【效能優化】極致優化抓取流程，提升運行效率：優化了連續執行抓取任務的效率，透過 304 Conditional GET 和 24 小時的搜尋快取機制，將重複抓取任務的耗時從數十秒大幅降低至秒級，極大提升了批次處理的效率。
  • 【架構穩定性】單一流程 (Single-Process) 執行與零接觸操作：將整個更新流程重構為單一進程，消除了過去依賴子程序和標準輸出解析的複雜性，使系統在 Ollama 服務中斷時能優雅地中止並記錄狀態，提升了整體穩定性。
  • 【API/CLI 變更】新增 `probe` 子命令：用戶現在可以使用 `tracker probe ` 命令，無需手動修改程式碼即可對任何網址進行來源探測和自動儲存。

v1.0 — 2026-06-10 ★ 1.0 Milestone

內容等同 v0.10、僅主版號進階至 1.0。 本版本將累積 10 個迭代版本的功能成果一次性升格為正式 milestone 釋出。

  • I — PATH 抓取排除 footer / about 雜訊： sources/path.py:_looks_like_article 新增 15+ pattern， 自動拒絕 privacy / accessibility / rights / terms / contact / link/index 等網站全域頁面（含日德法 datenschutz、mentions-legales、ご利用にあたって 等）， 解決 NISC、BSI 等政府站把 footer 當文章抓進來、body_len=0 的雜訊問題。
  • J — Cross-detection 以分類為權威訊號： cross.belongs_to 新增 article_category 參數作為 Signal 0； 當文章分類落在另一 tracker 白名單時，視為跨主類強訊號。 STRONG_MARKERS[security] 擴充 malware / MaaS / stealer / trojan / phishing / backdoor / C2 / exfiltration / DDoS 等。 實測修補一個 eu_cra-only Minecraft 惡意軟體文章為 trackers=eu_cra,security； cross-scan 全庫補回 10 個遺漏的多歸屬。
  • F — pipeline 加 token telemetry： tracker pipeline 結尾統計所有 subprocess 的 stdout+stderr 累計位元組， 並以 ÷4 推算 Claude token 等價量。 樣本：1 tracker 6 天 window ≈ 1,182 bytes ≈ 295 tokens， 讓使用者直觀掌握「若由 Claude 編排會花多少 token」。
  • G — Wayback Machine fetcher： 新模組 sources/wayback.py，PATH 階段在 live 抓取回 0 hits 且非 accept_all 時，自動 fallback 到 archive.org 最近 snapshot。 builtins 加 stan4cra.eu、cencenelec.eu。 實測 STAN4CRA 回 10 個 CRA 標準 sub-page（cenclcjtc13、clctc47x、centc244…）； ENISA / BSI CRA 頁面從未存檔，靜默降級無錯誤。
  • 累計 10 個版本成果：v0.1 scaffold → v0.5 多 tracker → v0.7 PATH + APAC 擴充 → v0.8 cross-scan --reverse → v0.9 一鍵 pipeline → v0.10/v1.0 品質與韌性收尾。當前覆蓋 security 22 entries / 5 categories / 30 keys， eu_cra 17 entries / 7 categories / 38 keys（含日韓新加坡視角）。
  • 已知非阻塞限制：ENISA CRA topic 與 BSI CRA 頁無 Wayback 存檔； KISA / ACSC / CERT-In RSS endpoint 多 404；DDG 重複查詢會被限流。 這些屬上游限制，不影響核心流程。
