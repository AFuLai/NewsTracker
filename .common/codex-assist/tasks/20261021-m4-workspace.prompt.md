1. Pure helpers, added INSIDE the TRACKER-STORE block (still pure, still exported from the returned object):
   - rangeOf(key, newest): returns {from, to} as YYYY-MM-DD. 'today' -> newest..newest; '7d' / '30d' / '90d' -> shiftDate(newest, -(N-1))..newest; 'year' -> newest's year-01-01..newest; 'all' -> '0000-01-01'..'9999-12-31'; 'y<YYYY>' -> YYYY-01-01..YYYY-12-31; 'd<YYYY-MM-DD>' -> that day..that day; 'c<from>_<to>' (two YYYY-MM-DD, swapped if reversed) -> from..to; anything else -> as '30d'.
   - dateCounts(list): plain object {date: count} over item._date.
