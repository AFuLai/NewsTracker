Implement reader-configurable "關注" (watch) highlighting in ui/index.html. Decision record: refs/plans/20261019-watch-and-frame-decisions.md (read it). Touch only ui/index.html. Vanilla JS, no CDN. Reuse the existing patterns: PRESETS / parseView-style pure functions, try/catch around every storage access, I18N.ui + applyLang for bilingual labels, buildCard / buildRiverRow for rendering, renderArticles for filtering.

1. `WATCH_RULES` constant. Each rule: id, zh/en label, and a match spec { trackers?: [...], categories?: [...], keywords?: [...] } — a rule matches an article when every given part matches: tracker in article.trackers (or the current tracker), category (raw category or effectiveCat) in categories, any keyword case-insensitively in title, title_en or tags. Rules:
   - cra_law  "EU CRA 法規更新" / "EU CRA regulation updates": tracker eu_cra, categories 法令更新, 法規與標準   (default ON)
   - cra_std  "EU CRA 標準更新" / "EU CRA standards updates": tracker eu_cra, categories 調和標準            (default ON)
   - cra_guide "EU CRA 合規指引／FAQ" / "EU CRA guidance / FAQ": tracker eu_cra, categories 合規指引     (default off)
   - kev      "KEV 已遭利用漏洞" / "KEV / actively exploited": keywords KEV, 已知遭利用, 遭積極利用, actively exploited (default off)
   - zeroday  "零時差漏洞" / "Zero-day": keywords 零時差, zero-day, 0-day (default off)
   - ransomware "勒索軟體" / "Ransomware": keywords 勒索, ransomware (default off)
   - nis2     "NIS2": keywords NIS2 (default off)
2. Storage: one localStorage key `tracker_watch` = {"v":1,"on":[rule ids],"kw":[custom keywords]}. Pure functions parseWatch(str) / serializeWatch(obj) / watchMatches(article, watch) -> array of matched labels (no DOM, no storage inside). Missing/bad JSON/unknown v -> defaults (cra_law, cra_std on, kw []), unknown rule ids dropped. Custom keywords: up to 20, trimmed, non-empty, each matched like a keyword rule, labelled with the keyword itself. When the URL query has pv=1, never write storage (same rule as tracker_view).

Keyboard accessible, Esc closes. Changes apply immediately (re-render) and persist.
