A modal dialog `#reader` (role=dialog, aria-modal=true, labelled by its title), centred, max-width ~760px, body text max-width 65ch with line-height ~1.85, full-screen below 768px. Content: meta line (type · date · source), title, the full summary (linkifyCVE(escHtml(...))), tags as #chips, a 閱讀原文 / Read original link (safeHref, target=_blank rel=noopener), and — when getReaderContext(...).sameCveArticles (pool = every article loaded in window.TRACKER_DAYS, collected with TrackerStore.collect over all loaded dates) is non-empty — a 同一事件 / Same event section headed with the shared CVE id and the count, listing each related article as "MM-DD title" (clicking one shows it in the reader).

Navigation: ‹ 上一篇 / 下一篇 › buttons and a position "i / N" over the workspace's currently shown list (getReaderContext prev/next); ArrowLeft / ArrowRight step, Escape closes; focus is trapped inside while open and returns to the card that opened it on close. Stepping updates the hash a=<id> (replaceState, as M2 does).
