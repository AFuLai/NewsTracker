# UX 改版樣板與使用者裁示（2026-10-19）

這裡的樣板來自 Design canvas（https://claude.ai/artifact/KgH9FchXHKA7Rtf8d1A4Lv）。檔案裡的數字是近 30 天實測。

## 使用者裁示
- **控制台：** 採用 `Main.dc.html` 的「單螢幕營運板」。
  - 頂部一條狀態帶。
  - 執行區塊在左，佔 7；發布、LLM、CRA 庫在右，佔 5。
  - 網站預覽改成底部可收合的抽屜。
  - 密度：字級 13px、卡片內距 10–12px、間距 10–12px、圓角 8px、用細框線取代陰影。
- **地圖模式不採用。**
- **我的關注：**
  - 不再依四個版面（資安、EU CRA、作業系統、CRA 庫）分，改依**新聞類型**分，並整合標籤。
  - 預設呈現是「分區」（`HubSections.dc.html`），可切換成「情勢儀表」（`HubTiles.dc.html`，深色科技感）。
  - 作業系統的平台（Linux、Apple、Android、Windows）改成標籤 chip 篩選。
  - CRA 庫暫不納入。
- **配色：** `Themes.dc.html` 的 10 款全部做成主題，讀者自選，設定存在瀏覽器。
